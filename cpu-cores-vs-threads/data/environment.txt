Benchmark configuration
-----------------------
sysbench CPU test:
- Prime limit: 20000
- Test duration: 30 seconds
- Five independent repetitions per thread count
- Thread counts tested: 1 through 12

7-Zip built-in benchmark:
- Three internal iterations per run
- Five independent repetitions per thread count
- Thread counts tested: 1 through 12

CPU affinity
------------
For thread counts 1 through 6, benchmark threads were assigned to logical
CPUs 0 through 5, placing one benchmark thread on each physical core.

For thread counts 7 through 12, the second hardware thread from each
physical core was added progressively using logical CPUs 6 through 11.

Topology comparison:
- Six physical cores, one hardware thread per core:
  CPUs 0,1,2,3,4,5
- Three physical cores, both hardware threads per core:
  CPUs 0,6,1,7,2,8

Validation procedure
--------------------
The tests were carried out on a private working server. There were no other
interactive users on the system during testing.

CPU activity was checked before and after every benchmark run using mpstat.
All 12 logical CPUs were sampled for five seconds.

A benchmark was only accepted if every logical CPU averaged at least 94%
idle over the five-second validation period.

If the CPU idle level fell below this threshold, usually as a result of a
scheduled background process or other temporary activity, the script waited
and repeated the check rather than immediately running or accepting the
benchmark.

The operating system, running kernel, CPU governor, and benchmark
configuration remained unchanged throughout the tests.
