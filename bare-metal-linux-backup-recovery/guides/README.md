# Guides

This folder contains technical guides and operational procedures related to the bare-metal Linux backup and disaster recovery strategy described in the [main article](../README.md).

The guides are intended primarily for system administrators and provide detailed, step-by-step instructions for tasks such as:

- Creating and maintaining ReaR backups.
- Configuring virtual machines to test backup restoration.
- Restoring a Linux system from a ReaR backup.
- Verifying successful recovery and troubleshooting problems.

These documents complement the main article, which focuses on the backup strategy, technical decisions, and lessons learned.

Additional guides will be added as procedures are developed, tested, and documented.
